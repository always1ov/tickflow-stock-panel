## ② 补充层 —— fork 加的, **只读底层不改它**

### 5. 通道阶段 `keltner_geometry.py::phase` —— 七档

`横盘中 / 刚启动 / 上升中 / 涨势转弱 / 走过头 / 下跌中 / 看不出`

另出两个不带数字的读数: **走到哪一步**(刚起步/走到中段/走了很长/走过头了)、
**还有没有劲**(还在加速/速度平稳/正在放慢)。

同码两说法: 走过头分 `涨过头`/`跌过头`; 涨势转弱在价格已跌穿三条线时说
`涨势已走完`(R215)。

**它是"均线中枢"的读数, 转得最慢。**

### 6. 事件分类 `keltner_geometry.py::event` —— 12 种

`突破尝试 / 突破站稳 / 趋势中提速 / 主升浪特征 / 涨势没劲 / 反弹遇阻 /
回撤结束 / 破位第一天 / 破位站稳 / 强势甩人 / 憋着劲 / 没什么事`

判据 = **位置 × 方向 × 时间**三样缺一不可。同一个「破上轨」在 UT 里是趋势内提速、
在 DT 里是反弹遇阻、在 NR 里第一天是突破尝试、第三天是突破站稳。

`confirmed` 字段区分「刚冲出去」与「守住了」—— 混在一起就是在鼓励追高。

### 7. 三尺度对齐 `keltner_geometry.py::alignment` (R224)

**报进度, 不报警。** 数三个尺度里有几个朝上:

```
价格 vs 短期中线   最快
六态(关键点)      其次
均线中枢          最慢
```

`3 三个尺度都朝上 / 2 正在转多 / 1 正在转空 / 0 三个尺度都朝下 / None 三条线还挤在一起`

三条线挤在一起时 `spread` 正负是噪声不是方向, 所以那时不数票。

### 22. 持仓档位 `today.py::holding_stance` —— 顺序即优先级

```
离场   出场线已破
减仓   趋势转空 → AI 看空 → 距出场线 <1.5% → 到上沿止盈
加仓   趋势多头 + AI 看多 + 刚转强 + 离线 >5%, 且**没贴上沿**

```

止盈减仓排在**所有风险驱动的减仓之后**, 且要三道闸: 短中期共振 + 浮盈 ≥10% +
转强已过 2 天 —— 都是为了防卖飞。

## 谁压谁 —— 优先级总表

```
出场纪律  >  时点  >  判定打架  >  距离  >  形态  >  没事
   ↑                     ↑
 fatal 独立           刻意排在「距离」之前:
 于另外三档           「还差 1.2% 到买点」会诱人下手,
                      而那正是不该下手的时刻
```

**跨层的三条硬规矩:**

1. **门槛缺数据放行, 但打分缺数据打折** —— 归一化保证"不因缺数据判你坏",
   置信系数保证"也不让你因此占便宜"
2. **注记一分不加一分不减** —— AI 信号 / 主线 / 胜率 / 龙虎榜 全在这一栏, 只显示不进分
3. **打架不替用户选边** —— 但必须让他看见

## [R229] 量化通道延申现在是什么身份

用户: 「撤销所有量化通道延申有关的东西」「ui 显示肯定是不变了」。

**它没有被删, 是被降级。** 第 5~10 层(阶段 / 事件 / 三尺度对齐 / 组合注记 /
匀速基准 / 频段能量)与 27 组合速查一个不少, 界面上原样都在; 变的只有一件事:

```
R195 ~ R228   三线间距 → 质地轴 .15      加速度 → 时机轴 .15
              压缩天数 → 磨底那一半的判据
R229 起       一分不加一分不减 —— 与 AI 信号 / 主线 / 胜率 / 龙虎榜同一栏
```

它要重新进分, 得先拿台账证明自己值那份权重。所以台账里那几个分组维度
(`chan_event` / `accel` / `combo` / `energy`)**特意留着** —— 台账「只记不反馈」,
记着不等于在打分, 而那是它唯一能自证的地方。
