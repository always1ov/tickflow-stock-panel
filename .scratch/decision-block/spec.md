## 一、先要定的三件大事

### A. 「做不做」与现有的「出手时机」是同一个问题, 只许一个答案

系统里已经有 `services/action_timing.py`(出手时机, 属 AI 分析系统, 不许改):
每只机会一句 **今天动手 / 收盘再动 / 不动手**, 判据全是价格(六态、离关键点多远、
贴不贴上轨、信号新不新、盘中涨了多少、大盘姿态)。图里这块问的正是同一件事
「现在该不该动手」。另起一套六条件, 就会出现决策台说「今天动手」、弹窗说「观望」。

- **建议**: 「做不做」那一格直接用出手时机的结论与理由(调用, 不改它), 条件清单只作为
  它的**解释**摊开 —— 一个结论, 一个产地。
- 另一条路: 新立一套六条件, 那就得决定两套打架时听谁, 以及决策台要不要跟着换。

> 待定 A: 用出手时机, 还是新立一套?

### B. 「目标一 / 目标二」到价就走, 与交易哲学冲突

「到上沿、涨得多、走了很长都不是卖点; 卖点是止盈线、生命线、六态转弱」
(硬约束第 10 条)。二型那三条推算位当卖点, R410 已经定了不用。

- **建议**: 「何时走」只放**现成的出场口径**: 出场线(`position_exit.py` 的 ATR 三阶段:
  止损 / 保本 / 移动止盈)、生命线(MA20, 跌破无条件清仓)、六态「跌破转弱」。
  上方的压力位可以画在图上当参考, **不叫目标、不当卖点**。
- 另一条路: 按图做目标一 / 二, 等于推翻 R410, 需要你明说。

> 待定 B: 何时走只放现成出场口径, 还是要目标?

### C. 盈亏比跟着 B 走

盈亏比 = (目标 − 进场) / (进场 − 止损)。B 选了不设目标, 盈亏比就没有分子:
要么用「上方最近的压力位」当分子(只作参考, 不当卖点), 要么这一条去掉。

> 待定 C: 盈亏比用最近压力位算, 还是去掉?

## 三、其余几样

- **做不做的档位名**: A 选出手时机 → 用它的三档原名(今天动手 / 收盘再动 / 不动手),
  不另起「观望 / 暂不开仓」(一个东西一个名字)。
- **在哪做**: 第 3 条的进场区, 带「距现价 −x%」。没有进场区时写「眼下没有重合的支撑」。
- **进度条**: 前三步可以直接用二型的形态进度(`lib/fib2Status.ts` 已有「上攻 N 天已结束 ·
  回踩第 N 天 · 有没有重合」): 等待上攻 → 回调中 → 已到位。「已进场」要知道你有没有持仓
  (持仓 / 批次数据现成)。「目标一 / 二 / 三」三步跟着 B 走 —— B 选不设目标就换成
  出场线的三阶段: 止损 → 保本 → 移动止盈。
- **到位提醒我**: 用现成的价格提醒(同一个提醒弹窗 / 监控规则), 价位填进场区上沿。
- **头部「结论」那一行**: 就写「做不做」那一格的结论, 不另写一句。
